# 极限的严格定义

一篇以「数列极限与 ε-N 定义」为主题的交互式推理小游戏，面向大学一年级《数学分析》第一周内容。

**[进入游戏](https://Wq-pW.github.io/math-analysis-limit/)**

## 关于本游戏

两千年来，「无穷小」与「趋近」一直困扰着数学家：芝诺说阿喀琉斯追不上乌龟，牛顿与莱布尼茨的无穷小量被贝克莱讥为「已死量的幽灵」。直到柯西与魏尔斯特拉斯，人们才把「极限」锻造成一套无懈可击的语言——ε-N 定义。

玩家扮演一位「审查官」，沿着历史线索逐页推进，在 12 个转折处做出推理选择：识破伪定义、击破反例、亲手写出极限的严格判决。

## 怎么玩

- 沿历史线索逐页推进，每个转折处有一道选择题，需根据当时掌握的证据选出最佳答案。
- 答错会出现明显提示和所选选项的解释，可重新作答；答对后出现确认提示才可继续；看提示不会直接通关。

## 计分

- 每题首次答对计 100%，纠错后答对计 60%，看提示后答对计 30%。
- 最终取各题平均分四舍五入，满分 100。
- 阅读速度不计分。

## 成绩与留言

- 通关后填写显示名，可把成绩上传到公开排行榜，或只写评论（星级可选）。
- 发布需登录 GitHub，由玩家本人确认；公开内容包括 GitHub 账号、显示名、成绩与评论。
- 榜单从本仓库的公开 Issues 自动生成：玩家提交后，GitHub Actions 运行 `community/sync.mjs` 重新生成 `community.json`，游戏页面实时读取显示。
- 关闭投稿帖，或由管理员添加 `community-hidden` 标签，可撤回对应记录。

## 本地运行

```sh
node --test community/community.test.mjs   # 校验解析与排行逻辑
node community/sync.mjs                     # 仅读取公开 Issues 并写本地 community.json（不发布）
```

直接打开 `index.html` 即可游玩（题目与计分离线可用；排行榜与投稿需联网）。
